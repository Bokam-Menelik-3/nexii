# 🧠 Nexii

> **Your life, adapted to you.**

Nexii is a personal productivity and wellbeing application designed to help you understand your current state, detect friction, and adapt the way you move toward your goals.

## ✨ What is Nexii?

Nexii connects your daily context with intelligent assistance:

```text
Your State
    ↓
Nexii Intelligence
    ↓
Understand
    ↓
Detect Friction
    ↓
Adapt
    ↓
Take Action
    ↓
Measure Progress

Core systems

🧠 Nexii Intelligence — understands your context

⚡ N1 — identifies what matters now

🌙 Aura — represents your overall state

🔋 Mental Battery — reflects your current capacity

✅ Tasks & Goals — organize what matters

🎯 Missions — turn goals into progress

⏱️ Focus — help you execute

📅 Agenda — understand your time

📈 Progression — measure your progress

🤖 Coach IA — conversational assistance

💰 Finance — manage your finances


🏗️ Built with

Flutter · Dart · Firebase · Node.js · Express · Gemini

🚀 Run Locally

Prerequisites: Flutter, Dart, Node.js

1. Clone the repository:

git clone https://github.com/Bokam-Menelik-3/nexii.git
cd nexii


2. Install Flutter dependencies:

flutter pub get


3. Install backend dependencies:

npm install


4. Configure your environment variables:

cp .env.example .env


5. Run Nexii:

flutter run



🔒 Status

Closed Beta

Nexii is currently being tested with early users while its experience and Intelligence layer are being refined.
